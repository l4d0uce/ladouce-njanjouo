==CSS== est un langage de description . il permet de faire la mise en forme visuelle du contenu .

L'éditeur dans lequel on ecrit du code permet d'écrire dans différents langages, dont le HTML et le CSS. Ce que nous ferons, c'est tout simplement de coder :

1. **un fichier de contenu en HTML** - qui aura l'extension  `.html`  ;
    
2. et **un autre fichier de style en CSS** - qui aura l'extension  `.css`.
 Pour les faire communiquer, il suffira d'ajouter une seule ligne de code dans le fichier HTML
